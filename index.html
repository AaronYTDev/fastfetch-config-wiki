SETUP

Installation

Get Fastfetch and fastfetch-config installed, then let the TUI take over the repetitive bits.

Stable install

The project provides a curl-based installer for the stable release.

curl -fsSL https://raw.githubusercontent.com/AaronYTDev/fastfetch-config/main/install-ff.sh | bash

Testing build

Use the testing installer when you intentionally want the less boring version.

curl -fsSL https://raw.githubusercontent.com/AaronYTDev/fastfetch-config/main/install-ff-testing.sh | bash
Read the script first if you're cautious. Piping a remote shell script straight into Bash is convenient, but downloading it, reviewing it, then running it is the more defensible habit.
Installer checks
  • Detects the distro
  • Checks jq
  • Checks chafa
  • Checks ImageMagick convert
  • Creates the Fastfetch config area
  • Installs the fastfetch-config command

FIRST RUN

Quick start

From zero to a customized terminal in a few deliberate steps.

01

Install Fastfetch

Fastfetch itself must be available on your system before this project can manage its configuration.

fastfetch --version
02

Install fastfetch-config

Run the stable installer, then make sure the command is on your PATH.

fastfetch-config
03

Make a change

Use the TUI to adjust modules, colors or logos. The tool writes your Fastfetch configuration for you.

04

Preview it

Run Fastfetch directly and inspect the result. Terminal configuration is best judged where it actually lives: in the terminal.

fastfetch
Tip: Keep a known-good config before doing a large redesign. Your future self is a separate person who deserves basic kindness.

Where it lives

The installer uses:

$XDG_CONFIG_HOME/fastfetch

When XDG_CONFIG_HOME is unset, that normally resolves to ~/.config/fastfetch.

CORE CONCEPT

Configuration

Fastfetch uses JSONC, JSON with comments. fastfetch-config edits that configuration rather than replacing Fastfetch itself.

The basic shape

{
  "$schema": "https://github.com/fastfetch-cli/fastfetch/raw/master/doc/json_schema.json",
  "logo": {
    "type": "auto",
    "source": "",
    "padding": { "right": 4 }
  },
  "modules": [
    "title",
    "separator",
    "os",
    "host",
    "kernel",
    "uptime",
    "packages",
    "shell",
    "de",
    "wm",
    "cpu",
    "memory",
    "gpu",
    "disk",
    "locale",
    "break",
    "colors"
  ]
}

logo

Controls how the Fastfetch logo is selected, rendered and padded.

modules

The ordered list of information Fastfetch prints. Order matters because it becomes the visual structure of your output.

Useful Fastfetch commands

fastfetch --gen-configGenerate a minimal config.
fastfetch --gen-config-fullGenerate a fuller config containing optional settings.
fastfetch --helpShow command-line help.
fastfetch -c all.jsoncTry an example/all-modules configuration when available.
fastfetch -s cpu:memory --format jsonInspect module data in JSON form.
Schema support: adding a JSON schema URL to the configuration lets editors such as VS Code provide completion and validation.

Custom module objects

Fastfetch also supports object-based module definitions, which are useful when you want to override labels, colors or formatting.

{
  "type": "os",
  "key": "OS",
  "keyColor": "blue",
  "format": "{name} {version}"
}

The exact options available vary by module. Use Fastfetch's module help, for example fastfetch -h cpu-format, when you need the supported format fields.

VISUALS

Logos & images

Fastfetch can use detected logos, built-in logos and file-based logos. The config tool also maintains a dedicated logos directory.

Auto detection

Keep "type": "auto" when you want Fastfetch to choose a suitable logo automatically.

Explicit source

Set a source when you want a particular built-in logo or a custom file path.

Custom files

The project uses ~/.config/fastfetch/logos as its logo storage directory.

Image helpers

The installer checks for chafa and ImageMagick's convert, which are used by the project's image-related workflow.

Handy Fastfetch logo commands

fastfetch --list-logosList available logos.
fastfetch --print-logosPrint available logo information.
PALETTE

Colors

fastfetch-config ships with a large named color map so you can work with readable names instead of remembering hexadecimal values for the rest of human history.

redorangegoldgreencyanbluepurplepink

The project contains 120+ named colors. Examples include red, crimson, gold, emerald, cyan, royalblue, indigo, purple, pink, silver, white and black.

Practical rule: use high-contrast key colors and let the logo carry the visual personality. Terminal output becomes unreadable surprisingly quickly when every line is trying to be the main character.

FIXES

Troubleshooting

When the terminal decides that today is the day it stops cooperating.

“fastfetch-config: command not found”

The installer places the command under ~/.local/bin. Make sure that directory is on your PATH, then restart your shell or reload its configuration.

echo "$PATH" | tr ':' '\n' | grep -F "$HOME/.local/bin"
Missing jq / chafa / ImageMagick

The installer checks for these dependencies. On unsupported distributions, install them yourself and run the tool again.

macOS is broken

That is not a shocking plot twist. The project explicitly labels macOS support as very experimental. Linux, particularly Arch-based systems, is the primary supported environment.

Fastfetch itself works, but the config looks wrong

Inspect ~/.config/fastfetch/config.jsonc. Check module order, JSONC syntax, logo paths and formatting options. The Fastfetch JSON schema is useful in an editor.

Custom logo does not render

Verify the file exists and is readable. Also check that the relevant image/terminal rendering tools are installed when your chosen logo mode needs them.

Important: a Fastfetch configuration can contain a command module capable of running shell commands. Treat untrusted configs like executable content and review them before use.

QUESTIONS

FAQ

The questions people eventually ask after poking the terminal with a stick.

Is fastfetch-config Fastfetch?

No. Fastfetch is the system-information program. fastfetch-config is a separate TUI project that helps manage a Fastfetch configuration.

Where is the config?

By default, the project uses $XDG_CONFIG_HOME/fastfetch, falling back to ~/.config/fastfetch.

Does it support every OS?

No guarantee. The repository says it works best on Arch Linux and Arch-based distributions. macOS support is explicitly described as very experimental.

Who made it?

The repository credits aaronYTDev and Madrinth.

Is this official Fastfetch documentation?

No. This is documentation for the fastfetch-config project. It uses Fastfetch's public documentation for concepts such as JSONC, modules and logos, while project-specific details come from the fastfetch-config repository.
