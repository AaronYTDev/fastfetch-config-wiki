fastfetch-config

A CLI tool to manage your fastfetch configuration with ease.

What is it?

fastfetch-config is a command-line utility that lets you manage every aspect of your fastfetch config — variables/modules, logos, OS names, colors, and more — without editing JSON files by hand.

Features

  • Add, remove, reorder, and configure modules (title, os, host, kernel, etc.)
  • Set logos from built-ins, local files, or auto-detection
  • Customize the displayed OS name
  • Configure logo colors by slot with color names or ANSI codes
  • Full backup & restore system for your configs
  • Interactive TUI menu for point-and-shoot configuration
  • Reset individual variables or the entire config

Quick Start

bash install-ff.sh
ff tui

Installation

Prerequisites

  • jq — JSON processor (installed automatically if missing)
  • fastfetch — the system info tool (installed automatically if missing)
  • bash & standard Unix utilities

Installing

Download install-ff.sh and run it:

bash install-ff.sh

The installer will:

  1. Detect your distro and package manager
  2. Install jq and fastfetch if needed
  3. Install the fastfetch-config script to ~/.local/bin/
  4. Create the ff alias script
  5. Set up a default config at ~/.config/fastfetch/config.jsonc
  6. Add ~/.local/bin to your PATH (if not already there)

Preserving Your Existing Config

By default, the installer overwrites any existing config. To keep yours:

bash install-ff.sh -nodelete

Sudo Password

The installer prompts for sudo only when installing missing packages. The script itself runs without root.

TUI Menu

The TUI provides an interactive text-based interface for managing your fastfetch config. Launch it with:

ff tui

Aliases: ff interactive, ff menu

Main Menu

OptionDescription
1) VariablesManage modules — add, remove, reorder, configure
2) LogoSet the display logo
3) OS NameSet the displayed OS name
4) ColorsSet logo color overrides
5) StatusView current configuration
6) ResetReset config or individual variables
7) Backup / RestoreCreate, list, restore, or remove backups
8) HelpView command reference
9) ExitExit the TUI and optionally run fastfetch

All navigation menus accept single-key input (no Enter needed).

Variables Submenu

The variables submenu shows the current module list at the top and offers:

  • Add — insert a module at its default position
  • Remove — delete a module by name
  • Move — reorder a module to a new position
  • Set property — add or change a key/value on a module
  • Easy set — set both the display label (key) and format in one step

Each operation pauses with Press enter to continue... so you can read the result before the screen refreshes.

Variables (Modules)

Variables are the building blocks of your fastfetch display. Each variable corresponds to a piece of system information.

Default Order & Positions

1separator
2osBecomes {type:"custom", key:"OS", format:"..."} when renamed
3host
4kernel

8de
9wm

Variable States

A variable can be either:

  • String — simple name like "kernel"
  • Object — enriched form with custom keys, e.g. {"type":"disk","folders":"/"}

When you set a property on a string variable, it automatically converts to an object. The reset command reverts an object back to its default string form.

Logo

fastfetch-config supports three logo modes:

Auto-detection

ff logo auto

Restores automatic logo detection based on your distro.

Built-in Logos

ff logo arch
ff logo ubuntu
ff logo fedora
ff logo steamos

Use any name from fastfetch --print-logos.

Custom File

ff logo ~/my-logo.txt
ff logo my-custom

Provide a path to a text file, or a name that matches a file in ~/.config/fastfetch/logos/. The file is copied into the logos directory automatically on first use.

Listing Built-in Logos

ff --list-logos

OS Name

Override the displayed operating system name:

ff osname "SteamOS holo 3.7.25 (steamdeck) x86_64"
ff osname auto

When you set a custom OS name, the os module is transformed into a custom module with key: "OS". Running ff osname auto restores the default os module with auto-detection.

OS Name + Logo Combo

ff osname-logo "MyOS 1.0"         # sets both OS name and logo to "MyOS 1.0"
ff osname-logo "MyOS" arch   # OS name "MyOS", logo "arch"

Colors

Override specific logo color slots (1–9):

ff color 1 blue
ff color 2 93
ff color 3 orange
ff color 4 bright-yellow
ff color 5 cyan
ff color list
ff color reset

Supported Color Values

  • Named colors: black, red, green, yellow, blue, magenta, cyan, white, orange
  • Bright variants: bright-black, bright-red, etc.
  • ANSI codes: 32, 93, 208, etc.

Note: The orange color is mapped to hex #FF8000 because ANSI 208 appeared as white on some terminals.

Backup & Restore

Save and restore your entire fastfetch configuration.

Creating Backups

ff backup                  # timestamp-based name
ff backup my-config        # named backup

Backups are stored as .jsonc files in ~/.config/fastfetch/backups/.

Listing Backups

ff backup list

Shows each backup with its creation date.

Restoring

ff restore my-config

Copies the backup back to config.jsonc, overwriting the current config.

Removing Backups

ff backup rm my-config
ff backup remove my-config

TUI Backup Menu

From the main TUI menu, select 7) Backup / Restore to access create, list, restore, and remove options.

Examples

Quick Start

bash install-ff.sh
ff tui
# Navigate the menu to configure your setup

Steam Deck / SteamOS Spoof

ff osname "SteamOS holo 3.7.25 (steamdeck) x86_64"
ff logo steamos

Full Custom Configuration

# Set up a gaming-themed display
ff osname "Arch Linux (gaming)"
ff logo arch
ff color 1 cyan
ff color 2 blue
ff color 3 magenta

# Add and configure modules
ff variable add gpu
ff variable add disk
ff variable set disk folders /
ff variable mv gpu 14           # move gpu to position 14

# Add a custom module
ff variable add custom
ff variable set custom key "My Info"
ff variable set custom format "Custom value here"

Backup Workflow

# Before making changes
ff backup before-tweaks

# Make your changes...

# If something goes wrong
ff restore before-tweaks

Minimal Config Reset

# Reset everything
ff reset

# Reset just one variable
ff reset colors
