Project status
fastfetch-config is actively evolving. It is best supported on Arch Linux and Arch-based distributions. macOS support is experimental.
01

What is fastfetch-config?

fastfetch-config is a terminal user interface designed to make managing a Fastfetch configuration easier. Instead of repeatedly editing configuration files, the tool provides menus for changing settings and working with logos, colors, modules and backups.

⌘

Terminal native

Designed around a TUI workflow that fits naturally into a Linux terminal.

✦

Personalization

Customize logos, colors and Fastfetch modules without starting from scratch.

↺

Backups

Keep configuration backups around so experimentation doesn't have to be terrifying.

02

Quick install

The stable installer can be run directly from the repository:

curl -fsSL https://raw.githubusercontent.com/AaronYTDev/fastfetch-config/main/install-ff.sh | bash

For the testing build, replace install-ff.sh with install-ff-testing.sh.

CONFIGURATION

Configuration

The project works with Fastfetch's JSON/JSONC configuration format and provides a friendlier TUI around it.

Default configuration

The installer creates a Fastfetch configuration with a logo section and a set of useful system-information modules.

{
  "logo": {
    "type": "auto",
    "source": "",
    "padding": { "right": 4 }
  },
  "modules": [
    "title", "separator", "os", "host", "kernel",
    "uptime", "packages", "shell", "de", "wm",
    "cpu", "memory", "swap", "gpu", "disk",
    "locale", "break", "colors"
  ]
}

Where does it live?

The project uses the standard XDG configuration location when available:

~/.config/fastfetchor $XDG_CONFIG_HOME/fastfetch

The tool's configuration file is config.jsonc; logos and backups are stored alongside it.

TROUBLESHOOTING

When things explode

A small collection of common things to check before blaming the terminal.

Why does the installer say a dependency is missing?

Make sure your package manager is available and that you have permission to install packages. The installer checks for jq, chafa, and ImageMagick.

Does it work on macOS?

There is experimental macOS support, but the project does not currently guarantee that everything works correctly there. Linux, especially Arch-based systems, is the best-supported environment.

Can I change the generated configuration manually?

Yes. The project is built around Fastfetch's normal configuration format, so manual editing remains possible. Just remember that future changes through the TUI may modify the same configuration.

Where should I report a bug?

Use the project's GitHub Issues page so the maintainers can track it properly.
