A TUI tool for managing Fastfetch configuration.

Project status: This project is experimental. It works best on Arch-based Linux distributions, and macOS support is very experimental.

fastfetch-config provides a terminal interface for working with your Fastfetch configuration, including configuration files and logos.

Install

Run the installer and let it set up the required dependencies and configuration directory.

Configure

Use the TUI to manage the Fastfetch setup stored in your config directory.

Installation

The project includes stable and testing installers.

Stable

Run the following command:

curl -fsSL https://raw.githubusercontent.com/AaronYTDev/fastfetch-config/main/install-ff.sh | bash

Testing version

For the testing installer:

curl -fsSL https://raw.githubusercontent.com/AaronYTDev/fastfetch-config/main/install-ff-testing.sh | bash

Dependencies

The installer checks for these dependencies and can install them when a supported package manager is available:

  • jq
  • chafa
  • ImageMagick, using convert

Supported package managers include pacman, apt, dnf, zypper, apk, xbps and emerge. Unknown distributions may require manual dependency installation.

Usage

The tool is designed to be used from the terminal.

Starting the tool

After installation, run the fastfetch-config command from your terminal.

The exact available options can change while the project is being developed. Treat the repository as the source of truth for current behavior.

Configuration directory

The project uses the standard Fastfetch configuration location:

${XDG_CONFIG_HOME:-$HOME/.config}/fastfetch

Configuration

Fastfetch configuration files are stored in the project's configuration directory.

Config file

$CONFIG_DIR/config.jsonc

The default configuration includes a logo section and modules such as the operating system, host, kernel, uptime, packages, shell, desktop environment, window manager, CPU, memory, swap, GPU, disk, locale, a break, and colors.

Logo settings

The default configuration uses an automatic logo source with right padding set to 4.

Colors

The project contains a large internal color map with more than 120 named colors for configuration use.

Logos

Custom Fastfetch logos are kept in the project's logos directory.

Location

$CONFIG_DIR/logos

The directory is created below the main Fastfetch configuration directory. The installer and configuration tool use it when working with logo files.

Backups

Backups are stored alongside the Fastfetch configuration.

Location

$CONFIG_DIR/backups

Keeping backups inside the configuration directory makes them easy to find without introducing another system-wide location.

Troubleshooting

A few things to check when the tool does not behave as expected.

Check your platform

The project is not confirmed to work on every operating system. Arch Linux and Arch-based distributions are the best-supported environment. macOS support is currently very experimental.

Check dependencies

Make sure jq, chafa, and ImageMagick are available if the installer could not provide them automatically.

Check the config directory

Verify that your Fastfetch configuration is under:

${XDG_CONFIG_HOME:-$HOME/.config}/fastfetch

Still broken?

Check the project's GitHub issues and the current repository files. This project is actively experimental, so documentation can occasionally lag behind the code. Humanity survives another day.
